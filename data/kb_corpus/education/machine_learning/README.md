# 机器学习课程知识库

本目录包含**机器学习**课程的完整教学资料，作为多智能体导学平台的初始知识库输入。

## 课程目录

| 章节 | 主题 | 关键词 |
|------|------|--------|
| 第1章 | 机器学习绪论 | 监督学习、无监督学习、强化学习、泛化 |
| 第2章 | 模型评估与选择 | 过拟合、欠拟合、交叉验证、ROC/AUC |
| 第3章 | 线性模型 | 线性回归、逻辑回归、正则化、L1/L2 |
| 第4章 | 决策树与集成学习 | 信息增益、剪枝、随机森林、GBDT/XGBoost |
| 第5章 | 神经网络基础 | 感知机、反向传播、激活函数、CNN/RNN |
