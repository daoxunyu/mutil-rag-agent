# 机器学习课程 - 学习指南

## 适用对象
计算机科学与技术、人工智能、数据科学等专业本科生（大二/大三）

## 先修要求
- Python 编程基础（NumPy、Pandas）
- 高等数学（微积分、线性代数）
- 概率论与数理统计基础

## 推荐学习路径

### 阶段一：基础入门（第1-2周）
1. 阅读第1章（机器学习绪论），建立整体认知
2. 阅读第2章（模型评估），理解过拟合/欠拟合
3. 动手实践：用 scikit-learn 训练第一个分类器

### 阶段二：核心算法（第3-4周）
1. 学习第3章（线性模型），掌握回归和分类基础
2. 学习第4章（决策树与集成学习），理解 Bagging/Boosting
3. 动手实践：实现 XGBoost 模型解决一个 Kaggle 竞赛问题

### 阶段三：深度学习入门（第5-6周）
1. 学习第5章（神经网络基础），理解反向传播
2. 了解 CNN/RNN/Transformer 的架构和应用
3. 动手实践：用 PyTorch 构建一个简单的 CNN 图像分类器

## 每章学习流程

1. 📚 **阅读教材章节** → 理解核心概念
2. 📝 **完成自测题** → 检验理解程度
3. 💻 **完成编程练习** → 动手实现算法
4. 📊 **查看拓展阅读** → 深入理解
5. 🤔 **向 TutorAgent 提问** → 解决疑惑
6. 📈 **获取学习评估** → EvalAgent 多维度评价

## 重点难点标注

| 章节 | 重点 | 难点 |
|------|------|------|
| 第1章 | 三大范式、泛化概念 | 偏差-方差权衡的理解 |
| 第2章 | 交叉验证、Precision/Recall | AUC-ROC 的深入理解 |
| 第3章 | 线性回归、梯度下降 | 正则化的数学原理 |
| 第4章 | 随机森林、XGBoost | Boosting 的权重更新机制 |
| 第5章 | 反向传播、CNN | 梯度消失/爆炸的原理和解决 |
