# 第3章 线性模型

## 3.1 线性回归 (Linear Regression)

线性回归试图学得一个通过属性的线性组合来进行预测的函数：
**f(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = w^T x + b**

### 最小二乘法 (Ordinary Least Squares)
目标：最小化均方误差 MSE = (1/n) Σ(yᵢ - ŷᵢ)²

### 梯度下降 (Gradient Descent)
- **批量梯度下降 (BGD)**: 使用全部数据计算梯度
- **随机梯度下降 (SGD)**: 每次使用一个样本
- **小批量梯度下降 (Mini-batch GD)**: 折中方案，最常用

### 学习率 (Learning Rate)
控制每次参数更新的步长。太大会震荡不收敛，太小会收敛太慢。

## 3.2 逻辑回归 (Logistic Regression)

虽然名字叫"回归"，但逻辑回归是**分类模型**，特别适合二分类问题。

核心思想：在线性回归的基础上套一层 **Sigmoid 函数**，将输出压缩到 (0, 1) 区间：
**σ(z) = 1 / (1 + e^(-z))**

### 损失函数：交叉熵 (Cross Entropy)
L = -[y log(ŷ) + (1-y) log(1-ŷ)]

### 多分类扩展
- **OvR (One-vs-Rest)**: 训练K个二分类器
- **Softmax 回归**: 直接输出K个类别的概率分布

## 3.3 正则化 (Regularization)

### L1 正则化 (Lasso)
在损失函数中加入权重绝对值之和：**λ Σ|wᵢ|**
→ 产生**稀疏解**，可用于特征选择

### L2 正则化 (Ridge)
在损失函数中加入权重平方和：**λ Σ wᵢ²**
→ 使权重趋于**小而均匀**，防止过拟合

### Elastic Net
L1 和 L2 的组合：**λ₁ Σ|wᵢ| + λ₂ Σ wᵢ²**

## 3.4 线性模型的优缺点

**优点**: 简单、可解释性强、计算高效、有解析解
**缺点**: 只能表达线性关系、对异常值敏感
