# 第5章 神经网络基础

## 5.1 感知机 (Perceptron)

感知机是最简单的神经网络模型，由两层神经元组成（输入层和输出层）。

**f(x) = sign(w^T x + b)**

局限：只能解决线性可分问题，连简单的 XOR 问题都无法处理。

## 5.2 多层前馈神经网络

### 网络结构
- **输入层**: 接收特征向量
- **隐藏层**: 非线性变换，提取高级特征
- **输出层**: 产生最终预测

### 激活函数 (Activation Function)

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | σ(x) = 1/(1+e^(-x)) | 输出(0,1)，有梯度消失问题 |
| Tanh | tanh(x) | 输出(-1,1)，零中心化 |
| ReLU | max(0, x) | 计算快，缓解梯度消失，最常用 |
| Leaky ReLU | max(αx, x) | 解决ReLU的"死亡"问题 |

### 万能近似定理
一个包含足够多隐藏神经元的前馈网络，可以以任意精度逼近任意连续函数。

## 5.3 反向传播算法 (Backpropagation)

反向传播是训练神经网络的核心算法：

```
前向传播: 输入 → 隐藏层 → 输出 → 计算损失
反向传播: 损失 → 输出梯度 → 隐藏层梯度 → 更新参数
```

核心是**链式法则**：∂L/∂w = ∂L/∂y · ∂y/∂z · ∂z/∂w

### 梯度消失与梯度爆炸
- **梯度消失**: 深层网络中梯度逐层衰减趋近于0（Sigmoid/Tanh常见）
- **梯度爆炸**: 梯度逐层放大导致参数剧烈更新
- **解决方案**: ReLU激活函数、Batch Normalization、残差连接(ResNet)

## 5.4 卷积神经网络 (CNN)

专为图像等网格结构数据设计。

### 核心组件
- **卷积层 (Convolution)**: 用卷积核提取局部特征，参数共享
- **池化层 (Pooling)**: 降采样，保留重要特征同时减小尺寸（Max Pooling最常用）
- **全连接层 (FC)**: 将所有特征综合用于最终分类

## 5.5 循环神经网络 (RNN)

专为序列数据设计（文本、语音、时间序列）。

### LSTM (长短期记忆网络)
通过三门机制解决RNN的长距离依赖问题：
- **遗忘门**: 决定丢弃哪些旧信息
- **输入门**: 决定存储哪些新信息
- **输出门**: 决定输出什么信息

### Transformer
基于注意力机制，摒弃了RNN的循环结构，支持并行计算。是现代大语言模型(如GPT、Claude)的基础架构。
