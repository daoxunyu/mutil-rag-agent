# 多智能体协同高校全专业个性化导学与资源生成平台
# 系统开发说明书

---

## 一、项目概述

### 1.1 项目背景

在数字化与智能化深度融合的时代，高等教育的个性化变革成为核心发展方向。不同学生在知识基础、学习能力、兴趣方向上的显著差异，使得标准化教学难以满足个性化学习需求。本系统借助大模型技术体系，融合 LangGraph 多智能体编排、RAG 知识检索、MCP 工具协议、SSE 流式输出等前沿 AI 技术，构建高等教育个性化学习资源体系，切实满足学生的个性化、多模态学习需求。

### 1.2 项目目标

- 通过自然语言对话自动构建 6+ 维度的动态学生画像
- 6 个角色化 AI Agent（画像/知识/资源/路径/辅导/评估）fan-out 并行协作
- 自动生成至少 6 种类型个性化学习资源（文档/PPT大纲/习题/视频脚本/代码案例/拓展阅读）
- 规划科学动态的个性化学习路径
- 提供智能辅导答疑与多维度学习评估

### 1.3 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | HTML5 + Tailwind CSS + Vanilla JS (SSE 流式接收) |
| 后端框架 | FastAPI 0.115+ (Python 3.11) |
| 多智能体编排 | LangGraph 1.0+ (StateGraph fan-out/fan-in) |
| LLM | DeepSeek v4-pro / v4-flash (via OpenAI-compatible API) |
| 向量数据库 | Milvus 2.4 (HNSW + COSINE) |
| Embedding | text-embedding-v4 / bge-m3 / TF-IDF (离线备选) |
| RAG 检索 | Parent-Child Chunking + Vector/BM25 Hybrid + RRF + bge-reranker-v2-m3 |
| MCP 工具 | FastMCP 3.x + langchain-mcp-adapters (5 个 MCP Server) |
| 流式输出 | SSE (Server-Sent Events via sse-starlette) |
| 会话存储 | Redis 7 |
| 数据持久化 | PostgreSQL 16 (事实库审计) |
| AI 辅助工具 | Claude Code (AI Coding Assistant)、科大讯飞相关工具 |
| 知识库规模 | 4202 chunks / 968 篇文档 (教育+技术语料) |

### 2.2 多智能体协作框架

系统核心采用 LangGraph StateGraph 实现确定性的 fan-out/fan-in 并行编排：

```
  [START]
     │
     ▼
  StudentContext    ← 加载学生画像、课程信息
     │
     ▼
  ResourcePlan      ← LLM 路由：分析学生需求，决定派遣哪些 Agent
     │
     ├──→ profile_agent    (📊 学习画像)
     ├──→ knowledge_agent  (📚 知识解析)      ┐
     ├──→ resource_agent   (🎯 资源生成)      │ fan-out
     ├──→ path_agent       (🛤️ 路径规划)      │ 并行执行
     ├──→ tutor_agent      (💡 智能辅导)      │
     └──→ eval_agent       (📈 学习评估)      ┘
     │
     ▼
  ResourceIntegrator  ← 归并所有 Agent 产出
     │
     ▼
  QualityReviewer     ← 内容安全检查
     │
     ▼
  LearningAdvisor     ← 生成学习建议
     │
     ▼
  Report              ← 渲染 Markdown 报告
     │
  [END]
```

**设计原则：**
- **上下文隔离**：每个 Agent 只读取 scoped 输入，中间推理不写入共享状态
- **黑板模式**：Agent 通过 `operator.add` reducer 安全并行写入共享状态
- **按需派遣**：ResourcePlan 根据学生需求关键词动态选择 Agent 子集
- **流式输出**：使用 `graph.astream()` 实时推送每个 Agent 的完成状态

## 三、核心功能实现

### 3.1 对话式学习画像构建 (ProfileAgent)

**实现方式：**
- 通过自然语言对话自动抽取学生特征
- LLM 结构化输出 10+ 维度画像 JSON
- 维度包括：知识基础（0-100评分）、认知风格（视觉/听觉/动手/阅读）、学习目标（短期/中期/长期）、薄弱环节模式、学习节奏、兴趣领域、前置知识、资源偏好（文档/视频/代码/互动）、学业状态（学期/GPA/学分）、画像总结

**技术亮点：**
- 非表单式交互，纯自然语言输入
- 支持画像随学随新（增量更新）
- LLM 失败时确定性兜底画像保证可用性

### 3.2 多智能体协同资源生成

系统包含 6 个专业教育 Agent，每个 Agent 是独立的 subagent：

| Agent | 职责 | 产出类型 |
|-------|------|---------|
| **ProfileAgent** | 学生画像分析 | 10维学习画像 |
| **KnowledgeAgent** | 知识点解析 | 结构化课程文档（含概念树/前置知识/思维导图） |
| **ResourceAgent** | 资源生成 | 8种资源：文档/PPT大纲/选择题/填空题/简答题/视频脚本/代码案例/拓展阅读 |
| **PathAgent** | 路径规划 | 分阶段学习路径（里程碑+周计划+考试准备） |
| **TutorAgent** | 智能辅导 | Markdown解答+图解+关联知识点+追问建议 |
| **EvalAgent** | 学习评估 | 多维评分+薄弱点+GPA预测+改进建议 |

**并行执行：** 6 个 Agent 通过 LangGraph fan-out 机制并行执行，wall-clock 时间约等于最慢单个 Agent 的耗时，大幅缩短总等待时间。

### 3.3 个性化学习路径规划 (PathAgent)

- 基于学生画像和知识基础生成分阶段学习路径
- 每个阶段包含：学习目标、推荐资源、预计时长、检查点（测验/编程/复习/考试）
- 支持周计划、期中/期末备考计划
- 自适应调整：根据学习评估结果动态优化路径

### 3.4 智能辅导答疑 (TutorAgent)

- 即时解答：文字详解 + 图解说明 + 短视频讲解要点
- 作业辅导：指导思路但不直接给出答案
- 考试复习：重点讲解常考知识点
- 关联推荐：相关知识点、建议追问、课程背景

### 3.5 学习效果评估 (EvalAgent)

- 多维度评分：知识掌握度、薄弱环节定位、GPA 预测
- 考试就绪度评估
- 学分进度追踪
- 动态调整：根据评估结果优化资源推送和学习计划

## 四、RAG 知识库系统

### 4.1 文档处理流水线

```
Markdown/文本教材
  → 标题层级切分 (H1/H2/H3)
  → Parent-Child Chunking (child=800字, parent=2400字)
  → Embedding (bge-m3, dim=1024)
  → 写入 Milvus HNSW 索引
```

### 4.2 检索流水线

```
用户问题
  → 向量检索 (Milvus HNSW, top_k=30)
  → BM25 稀疏检索 (内存索引, 纯Python实现)
  → RRF 融合 (bm25_weight=0.4, rrf_k=60)
  → Parent去重 (按parent_id归并, 保留完整段落)
  → bge-reranker-v2-m3 精排
  → 返回 top-3 parent context
```

### 4.3 评测指标

| 指标 | 数值 |
|------|------|
| Hit@3 | 1.000 |
| MRR@3 | 0.930 |
| Recall@3 | 1.000 |
| Faithfulness | 0.913 |
| Answer Relevancy | 0.936 |

## 五、用户体验设计

### 5.1 交互特性

- **SSE 流式输出**：所有 AI 生成内容实时流式推送，避免长时间白屏等待
- **Markdown 渲染**：学习报告、答疑解答使用丰富的 Markdown 格式展示
- **Agent 进度追踪**：6 个 Agent 协作过程可视化，每个 Agent 完成即展示产出
- **Toast 通知系统**：统一的非阻塞操作反馈
- **响应式设计**：适配桌面和移动端

### 5.2 防幻觉与内容安全

- **结构化输出约束**：所有 Agent 使用 JSON Schema 约束输出格式，减少自由发挥
- **确定性路由**：ResourcePlan 使用规则 + LLM 双层路由，避免随机派遣
- **质量审查节点**：QualityReviewer 自动检测空输出、格式错误
- **内容长度限制**：Agent 输出限制在合理范围内，避免无意义长篇生成
- **来源标注**：RAG 检索到的知识片段在回答中标注来源

## 七、创新实践与技术亮点

1. **LangGraph 确定性编排**：区别于让多个 LLM 自由对话的方案，本系统使用 StateGraph 实现确定性 fan-out/fan-in，每个 Agent 上下文隔离，通过结构化 Evidence 归并结果，避免多 Agent 对话失控。

2. **Parent-Child RAG**：创新的文档切分策略，小块用于精确向量召回，大块用于完整上下文提供给 LLM，兼顾检索精度和推理质量。

3. **Hybrid + RRF 融合检索**：向量检索与 BM25 双路召回后通过 Reciprocal Rank Fusion 融合，本地 bge-reranker 精排，在 50 题评测集上达到 Hit@3=100%。

4. **Skill/Guard 双层路由**：ResourcePlan 先通过关键词规则快速匹配 Agent，再由 LLM 验证和补充，既保证响应速度又具备灵活性。

5. **多模态资源生成**：单个 ResourceAgent 可生成 8 种类型的教育资源，覆盖从理论学习（文档/PPT）到实践应用（代码/视频脚本）的全场景。

6. **流式体验闭环**：从 API 到 Agent 到前端，全链路 SSE 流式输出，学生可实时看到生成进度而非长时间白屏等待。
