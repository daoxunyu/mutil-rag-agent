## 一、演示 PPT 大纲建议 (7 页)

### 第 1 页：封面
- 项目名称：多智能体协同高校全专业个性化导学与资源生成平台
- 团队信息 + 学校
- 赛题：A 组 - 多智能体协同高校个性化导学与资源生成

### 第 2 页：痛点与创新价值 (35%)
- **痛点**：学生面临资源繁杂、缺乏个性化指导、传统系统无多模态能力
- **创新点**：
  1. 6 Agent 并行协作 (LangGraph deterministic orchestration)
  2. 对话式画像 (10 维度，非表单)
  3. 8 种多模态资源 (文档/PPT/题库/视频/代码/实验)
  4. Parent-Child RAG + Hybrid 检索 (Hit@3=100%)
  5. 全链路 SSE 流式 (零白屏等待)

### 第 3 页：技术架构 (45%)
- 架构图：前端 → FastAPI → LangGraph (6 Agent fan-out) + RAG + MCP
- 多智能体编排图：StudentContext → ResourcePlan → [6 Agent 并行] → Integrator → Review → Report
- 技术栈表 (FastAPI, LangGraph, DeepSeek v4, Milvus, Redis, PostgreSQL)

### 第 4 页：核心功能演示 (45%)
- **功能 1**：对话式画像构建 (截图/动图)
- **功能 2**：6 Agent 协作资源生成 (截图：输入→6 Agent 并行→Markdown报告)
- **功能 3**：个性化学习路径 (截图：5阶段路径+周计划+考试复习)
- **功能 4**：智能辅导答疑 (截图：Streaming SSE + Markdown 渲染)

### 第 5 页：加分项展示
- **智能辅导**：Markdown 解答 + 表格 + 代码 + Mermaid 图
- **学习评估**：多维评分 + GPA预测 + 学分进度
- **知识库 RAG**：4202 chunks, Hybrid BM25+RRF+Rerank
- **学情分析**：5 个快捷场景 + AI 诊断

### 第 6 页：技术创新与防幻觉
- LangGraph 确定性编排 (非自由对话)
- Skill/Guard 双层路由 (规则+LLM)
- QualityReviewer 质量审核节点
- 结构化 JSON Schema 约束输出
- 来源标注 + 长度限制

### 第 7 页：总结与展望
- 覆盖赛题全部基本功能 + 2 个加分项
- 4202 文档的 RAG 知识库
- 开源组件声明
- 后续：多模态视频生成、移动端 App

## 三、AI Coding 工具使用说明

本系统在开发过程中使用了以下 AI 辅助工具：

| 工具 | 用途 | 使用方式 |
|------|------|---------|
| **Claude Code** | AI Coding Assistant | 代码生成、Bug修复、UI优化、文档撰写 |
| **DeepSeek v4** | 大语言模型 | 系统运行时 LLM 调用（非开发工具） |
| **科大讯飞工具** | AI 辅助开发 | 代码质量检查与优化建议 |

**声明**：所有 AI 生成的代码均经过人工审查、测试验证和必要的修改优化，确保代码质量和系统稳定性。AI 工具主要用于加速开发迭代，核心架构设计和业务逻辑由团队自主完成。

## 五、环境复现指南（评委使用）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动基础设施 (需 Docker)
docker compose up -d

# 3. 配置 API Key
cp .env.example .env
# 编辑 .env 填入 DEEPSEEK_API_KEY

# 4. 导入知识库 (可选，使用离线 TF-IDF embedding)
python scripts/ingest_kb_corpus.py --reset

# 5. 启动应用
# Windows: powershell -File .\run.ps1
# 或手动:
python mcp_servers/system_server.py &
python mcp_servers/websearch_server.py &
python mcp_servers/network_server.py &
python mcp_servers/docker_server.py &
python mcp_servers/winlog_server.py &
uvicorn app.main:app --host 0.0.0.0 --port 9900

# 6. 访问 http://localhost:9900
```
