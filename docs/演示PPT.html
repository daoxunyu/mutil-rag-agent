🛡️ 质量保障与防幻觉机制

🔒 结构化输出约束

所有 Agent 使用 JSON Schema 约束输出格式，LLM 必须输出符合预定义结构的 JSON，大幅减少自由发挥的幻觉空间

🎯 确定性路由 + LLM 验证

ResourcePlan 先通过关键词规则快速匹配 Agent，再由 LLM 验证和补充，避免纯 LLM 路由的不确定性

✅ QualityReviewer 审核节点

Agent 产出必经质量审核节点：自动检测空输出/格式错误/内容安全，LLM 二次审查事实性错误

📏 内容长度硬限制

Agent 输出限制在合理范围，避免 LLM 无意义长篇生成和幻觉扩散

🏷️ 来源标注

RAG 检索到的知识片段在回答中标注来源文档，学生可追溯原始资料验证信息准确性

🔄 兜底机制

LLM 失败时自动降级为确定性规则生成，确保系统始终有可用的基础内容输出
