## 六、已知限制与后续规划

1. 多模态视频/动画生成依赖外部模型，当前版本通过视频脚本生成间接支持
2. TF-IDF 嵌入为离线备选方案，语义检索精度低于 bge-m3 等专业嵌入模型
3. 移动端适配基础完成，可进一步优化触屏交互
4. 大模型 API 依赖网络，离线环境下部分 AI 功能不可用
